# 六足步态实验：机制与运行记录

[打开交互实验](https://weisiwu.github.io/threejs-demo/#/demo/hexapod-robot)

## 先看机制

六足机器人可先拆成足端轨迹和单腿逆运动学。三足步态按 i%2 分组，相邻两组错半周期；ripple 将六条腿依次错开六分之一周期。

两段腿长分别为 1.55 与 1.8。足端在支撑段保持地面高度，摆动段用 sin(2πp) 抬脚；平面目标由余弦定理求肩肘角，再旋转到每条腿的局部朝向。不可达时保留该腿上一有效姿态。

## 如何核对

切换 tripod 与 ripple，逐步推进观察抬脚分组；增加抬脚高度检查误差读数与可达范围。

通用控件可以暂停、推进一秒和重置。推进一秒实际调用二十次 0.05 秒更新，因此机构约束与任务状态仍经过正常更新流程；它不是只把时间显示改大一秒。浏览器页签隐藏时不积累缺席时间，自动单步长上限为 0.05 秒。

## 原资料与复现范围

本例显示六条腿的最大末端回算误差，不能据此证明机器人不会跌倒。没有触地力、躯干平衡、惯性或舵机协议。原仓库的全模型和许可未完整确认，因此没有镜像其整套实现。

几何运动学示意；未包含舵机限位、碰撞、接地受力或真机验证。

来源包括文章或固定提交源码。复现保留可讨论的机制，界面与几何由本仓库重新实现；原工程依赖、全部资产和部署配置没有直接迁移。
