# 扑翼机构：机制与运行记录

[打开交互实验](https://weisiwu.github.io/threejs-demo/#/demo/ornithopter) · [阅读相关文章](https://imgen.baoganai.com/knowledge/read/dilum-x-ornithopter)

## 先看机制

扑翼机构由曲柄和两根输出杆形成闭环。两个约束圆的交点决定翼根连接点，左右侧共享相位并镜像。

曲柄半径 0.35，固定输出点 (1.5,0)，连接半径为 1.5 和 1.35。选另一圆交点会改变装配分支；翼幅参数只缩放翼板，不改变约束杆长。残差从求出的连接点到曲柄端重新测量。

## 如何核对

慢速推进观察左右对称，再切分支；改变翼幅后，杆长残差仍应接近浮点误差。

通用控件可以暂停、推进一秒和重置。推进一秒实际调用二十次 0.05 秒更新，因此机构约束与任务状态仍经过正常更新流程；它不是只把时间显示改大一秒。浏览器页签隐藏时不积累缺席时间，自动单步长上限为 0.05 秒。

## 原资料与复现范围

翼板姿态采用输出方向的缩放角度，是可读的机构示意。没有翼面升力、惯性、柔性铰链或飞行控制。手稿风格和流畅运动都不能证明这组参数能驱动实体飞行器。

运动学原型，无气动、驱动器或飞行验收。
