# 步行连杆机构：机制与运行记录

[打开交互实验](https://weisiwu.github.io/threejs-demo/#/demo/strandbeest)

## 先看机制

机构复现不能靠给每根杆写一条独立动画。Jansen 腿由八个点与十二条杆构成，曲柄固定长度 15，其余节点依次由两圆交点求出。

固定点为 (0,0) 与 (-38,7.8)，曲柄端为 (15cosθ,15sinθ)。每次求交保留指定 x 或 y 方向的装配解；镜像操作翻转 x 而保持所有距离。杆长残差从最终坐标重新量出。

## 如何核对

减慢曲柄，推进一秒观察足端；切换镜像后对照杆长残差。若圆不相交，求解器返回错误，不把 sqrt 的负数隐藏成 NaN 画面。

通用控件可以暂停、推进一秒和重置。推进一秒实际调用二十次 0.05 秒更新，因此机构约束与任务状态仍经过正常更新流程；它不是只把时间显示改大一秒。浏览器页签隐藏时不积累缺席时间，自动单步长上限为 0.05 秒。

## 原资料与复现范围

复现安排六组腿，左右三组相位错开 120°。单位测试覆盖 360 个整数角度与两个镜像分支。镜像腿不等于证明足端连续接触地面；实际材料、摩擦、驱动和地面运动都没有模拟。

复现几何连杆机制；没有动力学、材料与实物行走证据。
